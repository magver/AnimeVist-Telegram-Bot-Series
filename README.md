# 🤖 AnimeVist Telegram Automation Bot & DevOps Console (24/7 Standalone)

Полностью автономный сервис и Telegram-бот для ведения официального канала **AnimeVist**, публикации серий (#онгоинг), мульти-источниковых новостей (#новости), тематических топ-подборок (#подборка), патчноутов (#patchnote) и закрепленного навигатора (FAQ/Pin).

Проект **на 100% отделён от клиентского приложения AnimeVist** — не требует React, Node.js или Electron, работает на чистой стандартной библиотеке Python 3 (0 сторонних зависимостей) и снабжён **веб-панелью управления** и **облачной консолью на GitHub Pages** с вечным хранением настроек в **Supabase**.

---

## 🌐 Веб-Консоль Управления (Два режима)

1. **[GitHub Pages Serverless Console (В браузере 24/7)](https://magver.github.io/AnimeVist-Telegram-Bot/)**:
   * Работает прямо из браузера без запуска скриптов на ПК.
   * Синхронизируется напрямую с вашей облачной базой **Supabase**.
   * Позволяет настраивать бота, публиковать кастомные посты, тестировать канал и вызывать подборки.
2. **Локальная DevOps Консоль (`start_web_dashboard.bat`)**:
   * Запуск на ПК или VPS (`http://localhost:5000`).
   * Встроенный непрерывный фоновый поток, живой терминал логов и расширенный студийный режим.

## 🐘 Облачное хранилище настроек (Supabase)

Все настройки бота и история опубликованных серий (`seen_episodes.json`, `seen_news.json`, `seen_compilations.json`) хранятся в вашей базе данных **Supabase**:
* Таблица `public.bot_config` — текущая конфигурация (токен, канал, интервалы, флаги отображения).
* Таблица `public.bot_seen_items` — реестр опубликованных серий, новостей и подборок (защита от дубликатов).
* Данные никогда не сбрасываются и не зависят от локальной файловой системы.

## 🚀 Автономный запуск 24/7 без затрат и без банковских карт

1. **GitHub Actions (Сервер не нужен вообще)**:
   * Файл `.github/workflows/auto_announcer.yml` запускается по cron каждые 15 минут в облаке GitHub бесплатно.
   * Файл `.github/workflows/manual_broadcast.yml` позволяет запускать публикацию серий, новостей или подборок через вкладку **Actions** в 1 клик с телефона.
2. **Локальный или VPS-демон (Python 24/7)**:
   * Запустите `run_daemon.bat` или `python main.py --daemon` на любом сервере (Ubuntu, Debian, Windows VPS) — демон работает непрерывно.

## 💻 Быстрый запуск на Windows

* `start_web_dashboard.bat` — запуск веб-консоли управления (`http://localhost:5000`).
* `start_menu.bat` — текстовое интерактивное меню в терминале.
* `run_daemon.bat` — непрерывный фоновый мониторинг серий, новостей и подборок.
* `1_post_episodes.bat` — разовая публикация новых серий.
* `2_post_news.bat` — разовая публикация новостей.
* `5_post_compilation.bat` — разовая публикация Топ-подборки аниме.
* `3_publish_patchnote.bat` — публикация патчноута релиза.
* `4_pin_navigator.bat` — закрепление поста-навигатора.
